### Design and Develop a Database GUI Application


Consider the FIFA World Cup 2026. Suppose we want to develop an application that stores
information about players, teams, and matches. Design and implement a database
application using Python (using tkinter and sqlite3 package) that provides the following
features:

1. Insert/update/delete players
2. Insert/update/delete teams
3. Insert/update/delete matches
4. Display player/team/match information on the UI
5. Search matches for a given team
6. Search matches for a given player
